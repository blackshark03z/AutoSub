# Universal Start — v1.16

Đọc `00_START_HERE.md`. Nếu owner đưa một outcome/feature/bug cấp cao cần nhiều hơn một patch rõ ràng, chọn **Goal Mode** và đọc `prompts/08_GOAL_ORCHESTRATOR.md`; không bắt owner tự chia task hoặc chuyển tiếp report.

Nếu change nhỏ, isolated, 1–2 file và root cause rõ, dùng Task Fast Lane trực tiếp.

Luôn xác minh Git/runtime/fingerprint trước write. Không sửa code nếu execution authority, scope hoặc lease chưa hợp lệ. Không đoán dữ liệu thiếu; tự inspect repo trước, chỉ hỏi owner khi đó là product/authority decision thật sự.
