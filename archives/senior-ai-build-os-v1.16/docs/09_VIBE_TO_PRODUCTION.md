# Vibe to Production

Experiments zone cho phép thử nhanh nhưng không được trở thành maintained code mặc định. Promotion gate yêu cầu owner-relevant behavior, hiểu được code path, tests/evidence phù hợp, data safety và cleanup prototype.

Anti-trash rules: không merge code không ai hiểu; không giữ duplicate path, dead feature flags, scratch artifact hoặc one-off provider wrapper sau promotion. Xóa prototype/dead code khi maintained replacement đã có evidence.
