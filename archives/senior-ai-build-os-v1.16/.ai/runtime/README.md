# Runtime machine state — v1.16

Generated by lifecycle/debug commands and intentionally excluded from application scope/Git status.

- `project.json`, `state.json`, `task.json`: machine mirrors used for validation/tooling.
- `task_baseline.json`: task-start fingerprints plus the frozen State Contract hash. Scope enforcement compares current worktree content against this baseline to derive `task_delta_files`.
- `state_failures/`: bounded failure signatures created only by `ai.py debug state-failure`; no global application tracing or raw state dump.

Lifecycle locks recover automatically when their recorded process is dead. Malformed recent locks still fail closed.

Do not reconstruct `task_baseline.json` from chat history. If it is lost during a live task, restore the same worktree/session state or restart the task from a trustworthy boundary.
