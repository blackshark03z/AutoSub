# Universal Start

Đọc `00_START_HERE.md`. Nhận diện đúng một mode, xác minh Git/runtime/fingerprint và trả Startup Brief theo risk tier. R0/R1 dùng brief gọn; R2/R3, takeover hoặc mismatch dùng brief mở rộng.

Không sửa code nếu execution authority, permission hoặc lease chưa hợp lệ. Ưu tiên `python scripts/ai_os.py begin/check/close` để bookkeeping deterministic. Không đoán dữ liệu thiếu; nêu `UNKNOWN` và cách xác minh.
