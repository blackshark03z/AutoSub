## When to create a Decision Record

Create one only when losing the decision could materially change a later session's scope, approach, acceptance, architecture, authoritative path or expensive research. Minimal record: identifier/title, Status, Date, Scope, Context, Decision, Why, Consequences, and Revisit When.
